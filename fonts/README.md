# Self-hosted typefaces

Fraunces normal/italic (400, 500) and Hanken Grotesk (400, 500, 600) retain the exact existing Google Fonts stylesheet and Unicode ranges. WOFF2 files are unmodified downloads from fonts.gstatic.com. The original stylesheet request and file URLs are recorded in manifest.json. Each family uses the included SIL Open Font License. The three Latin faces are preloaded with font-display: swap; other subsets load when needed.
